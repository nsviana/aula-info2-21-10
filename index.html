01 · Conceito

Um vetor guarda vários valores

02

Variáveis separadas

let nota1 = 8;
let nota2 = 7;
let nota3 = 9;

Para muitos valores, repetir variáveis dá trabalho.

Um vetor

let notas = [8, 7, 9];

O array notas reúne os valores em uma sequência.

Em JavaScript, o vetor é criado com colchetes []. Cada valor é um elemento.
02 · Posições

O índice começa em zero

03
let frutas = ["maçã", "uva", "pera"];

frutas[0] // "maçã"
frutas[1] // "uva"
frutas[2] // "pera"
frutas.length // 3

Posição e índice

  • Primeiro elemento: índice 0
  • Segundo elemento: índice 1
  • Último índice: length - 1
A posição humana 1 corresponde ao índice 0 no código.
03 · Percorrer

for visita cada posição

04

Exibir todos os elementos

let frutas = ["maçã", "uva", "pera"];

for (let i = 0; i < frutas.length; i++) {
  console.log(frutas[i]);
}

Como o laço avança

i vale 0, depois 1, depois 2.

frutas[i] acessa o valor naquela posição.

i < frutas.length para ao chegar ao fim.

Use i < vetor.length para percorrer qualquer tamanho de vetor.
04 · Acumulador

Somar os valores do vetor

05
let notas = [8, 7, 9];
let soma = 0;

for (let i = 0; i < notas.length; i++) {
  soma += notas[i];
}

let media = soma / notas.length;
console.log(media); // 8

Ideia principal

Comece com soma = 0.

Em cada volta, acrescente o valor atual.

Depois divida pela quantidade de elementos.

05 · querySelector

Um elemento: querySelector

06

Seleciona o primeiro elemento encontrado com o seletor CSS informado.

HTML

<p class="mensagem">Olá!</p>
<p class="mensagem">Bem-vindo!</p>

JavaScript

let primeiro = document.querySelector(".mensagem");
console.log(primeiro.textContent); // Olá!
querySelector() retorna um elemento. Use #id para id, .classe para classe e o nome da tag.
06 · querySelectorAll

Vários elementos: querySelectorAll

07

HTML

<p class="mensagem">Olá!</p>
<p class="mensagem">Bem-vindo!</p>
<p class="mensagem">Vamos programar.</p>

JavaScript

let mensagens = document.querySelectorAll(".mensagem");

for (let i = 0; i < mensagens.length; i++) {
  console.log(mensagens[i].textContent);
}
O resultado é uma coleção de elementos (NodeList). Percorra a coleção usando índice e length.
07 · Comparação

Do array aos elementos do DOM

08

Array criado no JavaScript

let cores = ["azul", "verde", "roxo"];
for (let i = 0; i < cores.length; i++) {
  console.log(cores[i]);
}

Elementos encontrados no HTML

let itens = document.querySelectorAll(".item");
for (let i = 0; i < itens.length; i++) {
  console.log(itens[i].textContent);
}
Nos dois casos usamos uma coleção, length, índice e repetição. O array guarda dados; a NodeList reúne elementos da página.
08 · Exemplo integrado

Contar itens na página

09

HTML

<ul>
  <li class="item">Caderno</li>
  <li class="item">Lápis</li>
  <li class="item">Borracha</li>
</ul>
<p id="saida"></p>

JavaScript

let itens = document.querySelectorAll(".item");
let texto = "";

for (let i = 0; i < itens.length; i++) {
  texto += (i + 1) + ". " + itens[i].textContent + " <br>";
}

document.querySelector("#saida").innerHTML = texto;
O índice começa em 0; i + 1 mostra uma numeração começando em 1 para a pessoa.

10 · Exemplo resolvido

Somar os elementos

11

Some os valores de [5, 8, 3, 4].

let valores = [5, 8, 3, 4];
let soma = 0;
for (let i = 0; i < valores.length; i++) {
  soma = soma + valores[i];
}
console.log("Soma:", soma); // 20

Como funciona?

O acumulador começa em zero. A cada volta, somamos o elemento da posição atual. Ao final, soma vale 20.

Mostrar somente os pares

let numeros = [4, 7, 10, 3, 12];
for (let i = 0; i < numeros.length; i++) {
  if (numeros[i] % 2 === 0) {

  }

Resultado

4
10

O resto da divisão por 2 é zero nos números pares.

12 · Exemplo resolvido

Encontrar a maior nota

13
let notas = [6, 9, 7, 10, 8];
let maior = notas[0];
for (let i = 1; i < notas.length; i++) {
  if (notas[i] > maior) {
    maior = notas[i];
  }
}
console.log("Maior nota:", maior); // 10

Estratégia

Comece com o primeiro valor do vetor. Percorra os demais e atualize maior sempre que encontrar um valor superior.

15 · Vetores

Adicionar valores com push()

17

O método push() coloca um novo elemento no final do vetor.

Exemplo resolvido

let nomes = [];
let notas = [];

nomes.push("Ana");
notas.push(8);

nomes.push("Bruno");
notas.push(6.5);

console.log(nomes); // ["Ana", "Bruno"]
console.log(notas); // [8, 6.5]

Incluindo valores digitados

let nome = document.querySelector("#nome").value;
let nota = Number(document.querySelector("#nota").value);

nomes.push(nome);
notas.push(nota);

Leia o campo, converta a nota para número e use push() para guardar os dois valores.

Cada chamada de push() acrescenta um elemento ao final do vetor. Agora você pode começar os vetores vazios e preenchê-los conforme os dados são informados.
